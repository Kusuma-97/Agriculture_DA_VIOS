# Agriculture Data Analysis - VIOS Major Project

## 📊 Project Overview

This repository contains a comprehensive analysis of seasonal agriculture performance across multiple Indian states and districts. The project analyzes 4,000+ farm records to identify key factors affecting crop yield, profitability, and sustainability.

## 📁 Contents

- **`seasonal_agriculture_performance_dataset.csv`** - Main dataset with 28 columns including:
  - Farm details (ID, State, District, Crop type, Season)
  - Environmental factors (Rainfall, Temperature, Humidity, Sunlight, Soil pH, Moisture)
  - Nutrient composition (Nitrogen, Phosphorus, Potassium)
  - Irrigation methods and water usage
  - Production metrics (Yield, Production, Market Price)
  - Financial analysis (Total Cost, Revenue, Profit)
  - Risk factors (Disease/Pest Risk)

- **`Agriculture_Data_Analysis.ipynb`** - Jupyter notebook with exploratory data analysis and visualizations

- **`VIOS_Major_Project_PPT_Submission.pptx`** - Presentation slides with key findings and recommendations

- **`Major Project_Seasonal Agriculture Performance Analysis..pdf`** - Detailed analysis report

## 🎯 Key Findings

### Dataset Summary
- **Total Records:** 4,000 farms
- **States Covered:** Multiple Indian states (Maharashtra, Tamil Nadu, Karnataka, Gujarat, Punjab, Telangana, Andhra Pradesh, Madhya Pradesh)
- **Crops Analyzed:** Wheat, Rice, Maize, Pulses, Cotton, Groundnut, Chilli, Sugarcane
- **Seasons:** Kharif, Rabi, Zaid

### Performance Metrics
- Yield analysis across different crops and seasons
- Profitability trends based on irrigation methods
- Water efficiency and sustainability metrics
- Correlation between environmental factors and production

## 🔍 Analysis Areas

1. **Crop Performance** - Yield and production analysis by crop type and season
2. **Regional Patterns** - State and district-wise agricultural productivity
3. **Environmental Impact** - Rainfall, temperature, and humidity effects
4. **Water Management** - Irrigation efficiency and water usage optimization
5. **Financial Analysis** - Cost-Revenue-Profit relationships
6. **Risk Assessment** - Disease and pest risk patterns

## 📝 Dataset Structure

| Column | Description |
|--------|-------------|
| Farm_ID | Unique farm identifier |
| State | Indian state |
| District | District name |
| Crop | Type of crop grown |
| Season | Growing season (Kharif/Rabi/Zaid) |
| Farm_Area_Hectares | Size of farm |
| Rainfall_mm | Annual rainfall |
| Avg_Temperature_C | Average temperature |
| Humidity_pct | Humidity percentage |
| Sunlight_Hours_Day | Average daily sunlight hours |
| Soil_pH | Soil acidity/alkalinity |
| Soil_Moisture_pct | Soil moisture level |
| Nitrogen/Phosphorus/Potassium_kg_ha | Nutrient content |
| Irrigation | Irrigation method (Drip/Flood/Sprinkler/Rainfed) |
| Yield_Tonnes_Ha | Crop yield per hectare |
| Production_Tonnes | Total production |
| Profit_INR | Net profit in Indian Rupees |
| Water_Efficiency_t_per_1000m3 | Water usage efficiency |
| Disease_Pest_Risk_pct | Risk percentage |
